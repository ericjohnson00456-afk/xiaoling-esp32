# 小聆 ESP32 板型适配

在目标仓库中遵循 [AGENTS.md](../../../AGENTS.md)，按任务选择以下步骤。
只分析硬件问题时先定位；只构建或烧录已有板型时直接核对目标与配置，无需新增适配代码。
沿用用户已明确的板型、设备、环境和操作授权，不因使用本 skill 重复确认。

## 确认硬件与接入方式

- 阅读目标板型已有的 `README.md`、`config.h`、`config.json` 和初始化代码；文件缺失时查找相近实现及硬件资料。新增板型的目录、Kconfig/CMake 注册和代码示例见 [自定义开发板指南](../../../docs/custom-board.md)。
- 核对具体型号与硬件版本、芯片、Flash、PSRAM 容量及 Quad/Octal 模式、显示分辨率与总线、音频链路、按键和电源管理。按需要检查共享总线、引脚冲突、屏幕或摄像头方向；不能仅凭产品名称认定硬件相同。
- 优先复用已有板型的驱动、构造过程和配置。公共功能使用现有接口，确有硬件差异时在板级处理；能力声明应与实际可调用功能一致。小应用的公共接入规则见 [指南中的 Lua 小应用能力](../../../docs/custom-board.md#lua-小应用能力)。
- 需要实板验证时，尽早检查已连接且获准使用的设备及串口；缺少设备再请用户连接。不为了纯代码分析而要求接设备。

## 构建与产物核对

使用 AGENTS.md 指定的工具链版本，在仓库根目录运行：

```sh
python scripts/build.py <板型>
```

`--name <变体>` 选择变体，`--list-boards` 查看目标。构建与产物说明见
[README](../../../README.md)。脚本会重建 `build/` 并修改生成的 `sdkconfig`；
先保留仍需使用的配置和产物。已有同名发布 ZIP 会跳过构建，验证新改动前移走旧包。
目标及配置未变化时可增量运行 `idf.py build`。

构建后核对：

- `sdkconfig` 中实际选中的 Kconfig 板型、芯片、Flash、PSRAM、分区和摄像头等开关。
- `build/compile_commands.json` 中实际编译的板级源码及产物名称；`BOARD_NAME` 不能替代 Kconfig 板型选择。
- 应用与资源是否装得进对应分区；资源文件及运行时加载路径是否匹配。
- 目标设备使用的 UART、原生 USB 等日志和 shell 通道是否与配置一致。

## 烧录与串口

- 烧录前确认当前实物与串口的对应关系，并释放占用该端口的监视器。设备重插后重新枚举端口；多台设备时不能只按端口顺序选择。
- 使用本次构建产物及其生成的 Flash 参数，常规入口为 `idf.py -p <串口> flash`。检查实际写入区域，保留 NVS 中的 Wi-Fi 和设备身份及已有小应用；应用或资源更新不默认全片擦除，也不以 Flash 备份作为前置步骤；固件和资源可从源码重新构建。
- 分区布局变化时，先比较设备当前与目标分区表，核对 NVS、`miniapp_src` 等持久化数据分区的偏移、容量及新镜像写入范围。若涉及移动、缩小或覆盖，说明需要重新配网、绑定或安装小应用等影响，按任务要求迁移或重建数据；不能仅以未全片擦除认定数据已保留。
- 字体、资源布局或分区表变化时，烧录相应资源或分区表；仅更新应用程序不能验证这些变化。PID/SID、运行环境和绑定状态只在任务要求时调整。
- 串口控制线和重新打开端口可能触发复位。烧录完成后核对校验结果及应用启动日志，不把烧录成功等同于应用已运行；停在下载模式时按板型说明复位。
- 连接失败时先检查端口重枚举、占用、线材和设备模式，不反复盲刷。无法继续时说明具体阻碍及已完成步骤。

## 真机验证与交付

按改动选择验证场景：启动与联网、目标功能、异常恢复、退出和资源释放。
公共改动选择能覆盖受影响能力的代表性硬件，不默认逐板修改或逐板烧录。

- 显示：检查实际屏幕布局、方向和裁切；有可用截图入口时导出真机截图，没有时请用户确认观感。
- 音频：检查实际 PCM 或播放终态、听感及相关并发场景；涉及实体按键时请用户确认操作结果。
- 小应用：按 [小应用文档](../../../docs/miniapp.md) 选择安装、操作、退出及恢复场景，检查能力上报与硬件一致。

缺少真机或复现特定边界时可使用 Espressif 官方 QEMU，已有入口见
[DF-K10 QEMU](../../../main/boards/df-k10/qemu/README.md)。明确其板型、外设和联网限制，
不把主机构建、模拟或其他板型的结果作为目标设备已验证。

若验证时增加了临时按键注入、调试服务或截图入口，交付前移除，并对移除后的固件
重新构建和验证。报告实际构建、烧录与真机观察结果及尚未验证的部分，结束后释放串口。
