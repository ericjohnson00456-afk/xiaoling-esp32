# 小应用验证

加载 ESP-IDF 5.4.4 环境后运行纯主机回归，不依赖开发板：

```sh
sh tests/miniapp/run_host_tests.sh
```

覆盖操作参数声明、严格类型和大小预算，合成器混音限幅与暂停定位一致性，HLS 播放列表和相对地址解析，以及真实 Lua VM 中的 TTS 异步结果、启动请求、取消和候选实例存档隔离。主机回归不验证 LVGL、FreeRTOS、网络或真实音频输出。

`smoke.lua` 是 CoreS3SE 的实机测试应用：按实际宽高绘制，点击计数，通过声明的操作测试 HTTP JSON、云端 TTS、四声部音效、在线音频暂停恢复和存档。`fetch` 操作需要返回 `{"value":42}` 的 HTTP 地址；`play` 需要实际可访问的 MP3 或 MPEG-TS AAC HLS 地址。源码字节数和 MD5 应按当前文件重新计算，并通过标准 MCP 安装工具传入。

实机回归应覆盖：下载长度及哈希错误、语法错误、启动异常、无限循环和超出堆预算均不能破坏旧应用；运行异常退出；重复安装复用状态；退出后没有延迟回调或音频；存档隔离和限频；闹钟冻结与恢复；实体功能键短按和持续 3 秒退出。结合实际屏幕截图与串口日志检查，临时上传、输入注入、截图和调试服务应在正式构建前移除。
